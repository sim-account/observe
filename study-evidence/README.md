# Practitioner-study evidence availability

The paper reports more than 20 practitioners from five multinational companies, four industries and three continents. Roles include process-excellence leaders, analysts, and mining/simulation experts. Participants inspected observations, adjusted recommendations, compared simulated KPIs, and gave structured-discussion feedback.

The paper summary describes perceived usefulness, value in contextual observations and executable parameter changes, and occasional difficulty understanding templates. Participants did not make actual operational decisions; operational usefulness was not measured.

This package includes paper-reported aggregates only. Supporting session protocols, discussion questions, transcripts, consent records, coded feedback, and participant-level evidence are not included, so the qualitative findings cannot be independently reproduced. Company logs and participant identities are not included.

The numerical evaluations run independently of these materials.
